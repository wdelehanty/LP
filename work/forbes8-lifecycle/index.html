Forbes / B2C 2019 TO 2021

Forbes8 lifecycle

Owned a B2C product lifecycle end to end: activation, engagement, retention, and LTV, with a feedback loop tying lifecycle sends to incremental sales.

Problem

For a consumer product, everything rides on what happens after signup. Somebody had to own that for Forbes8: getting new users to value fast, keeping them around, and figuring out which emails moved sales instead of just getting opened.

What I built

The site and the activation plan

Design and engineering were booked, so I built the pages with the HTML and CSS I'd picked up doing demand gen. Then the activation plan: the sequence a new user hits in their first few days, pointed at getting them to value fast.

Engagement, retention, and the feedback loop

Engagement and retention programs across the subscriber base, pointed at LTV. The incremental-sales feedback loop is what let us tune programs against sales instead of opens.

Stack

html / css / email automation / funnel reporting

Outcome

No public number on this one. But it's where I learned to run lifecycle the way I still run it: own the whole thing, build the measurement in early, judge the program on sales. Everything I did later in B2B lifecycle started here.

Before thisI spent 2015 to 2018 as a sales planner, so I knew how media actually got sold before I ever ran lifecycle. That's why all of it points at revenue.
