How this site was built

The build

Hand-written HTML and CSS with one small script for motion. No framework, no CMS, no build pipeline beyond the Python scripts that stamp the version, inline the diagrams, and render workflow exports. Hosted on GitHub Pages. Pages start from a shared skeleton and get written by hand from there.

Type is Barlow for display and body, Barlow Condensed for labels and stats, IBM Plex Mono for code and captions, all self-hosted as woff2 files totaling about 60K. The palette is a warm gunmetal with one accent, a safety yellow borrowed from workwear, because most of what this site shows is diagrams and dashboards and they read best on a dark ground.

The diagrams

Workflow diagrams are rendered from actual n8n workflow exports into the site's own colors and type. Architecture diagrams are drawn by hand in the same language, in the site's own tokens, so they inherit the page fonts and colors. Each carries a DWG marker, and the workflow ones say which export they came from. The photography is mine, shot on the property, except the brushed steel texture behind the headers, which is by apryan widodo on Unsplash. Internal tools show up as drawings or samples, never with real numbers in frame.

Deliberately left out

No analytics scripts, no cookies, no consent banner because there is nothing to consent to. The one script that phones home is a visit beacon that fires only when a URL carries a code I handed out myself, and it reads nothing from your browser. Motion is deliberate and light: things rise once as they enter, and everything stands still if your system asks for reduced motion. No gradients, no testimonial carousel, no logo strip, no stock illustration posing as my life. No em-dashes either, down to the commit messages. Long story.

The rules the copy follows

Every number traces to a maintained achievement inventory or does not appear. Revenue I influenced is called influenced. Things built and not yet launched say so. Companies appear by name only where they already appear on my public resume; everyone else is described generically on purpose.
