Personal builds

Things I built because I wanted them to exist. Same habits as the work: take it apart, understand it, wire it back together better.

The job search machine

Problem
A serious search is a pipeline, and running a pipeline by hand out of browser tabs wastes the hours that should go into the applications themselves.
Built
An artifact engine that runs deep research per company, scores concepts, and gates anything that should not be sent. A morning digest where each outreach draft gets a one-tap approve-and-send. A visit beacon on the work samples that alerts my phone when a prospect opens one. A Friday scorecard pulled from the pipeline database, and a notify hook so long builds can tell me they finished. Notion is the source of truth throughout.
Stack
claude code / n8n / notion / gmail

Life OS in Notion

Problem
Life admin scattered across inboxes, memory, and paper means the same decisions get made twice and the maintenance gets remembered late.
Built
An operating manual, an Inbox, a Knowledge Base, a Decisions Log, Active Sprints, a Weekly Review, and a Home and Garage Maintenance database. Three capture hooks feed it without me touching Notion: email forwards land in the Inbox, a webhook writes to the Knowledge Base, and Home Assistant posts maintenance events on its own.
Stack
notion / n8n / home assistant / gmail

Home Assistant

Problem
A house full of smart devices from different eras, none of them speaking to each other, half of them running someone's cloud.
Built
Three waves of cleanup and build: naming conventions, consolidated integrations, old hardware retired, and automations that earn their keep, including a goodnight lockdown and a doorbell chime. Maintenance events post themselves to the Life OS database in Notion.
Stack
home assistant / n8n / notion

Wardrobe app

Problem
Getting dressed for the right context is a lookup problem, and nobody in the house wanted to be the lookup table.
Built
Wardrobe and Outfits databases in Notion with a standardized schema across 14 use contexts, a Cloudflare Worker API on top, AI photo cataloguing to get items in without data entry (289 items in so far), and an iOS app in progress with TestFlight for family use.
Stack
notion / cloudflare workers / ios (testflight)

Event pacing dashboard

Problem
An events team watching registration and revenue pacing across a portfolio should not have to assemble the picture by hand every Monday.
Built
A standalone app on the Bizzabo API for a media company's events team: registration and revenue pacing, year over year comparisons, promo attribution, Monday digests, and an AI question-and-answer layer on top of the data.
Stack
bizzabo api / ai q&a layer

The fireworks show

Problem
There was no problem. It is a fireworks show.
Built
An annual show programmed on an Ignite cue system and synced to music, with a 2-second delay baked into every cue to account for igniter lag. The neighbors get a show; I get a sequencing problem with a hard deadline and zero retries.
Stack
ignite / a music track / a checklist
