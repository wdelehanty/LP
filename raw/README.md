# Photo drop

Drop originals here (any size, any name, phone shots fine). This folder
is gitignored, so nothing you put here goes public. The processing step
resizes, grains, renames into v2/assets/img/, and wires each shot into
its page.

The shot list lives in the site build notes; short version: coop
(mid-build and finished), the shop, the property, Home Assistant
dashboard plus one automation screen, Life OS hub in Notion, wardrobe
closet gallery in Notion, event dashboard with numbers scrubbed, one
scrubbed Forbes email template and landing page, Under 30 Summit shots,
fireworks setup if one exists.

## Shot list, v2.6.1

- shop, clean, wide from the door, lights on
- skiing, fishing, boat or water, the dog, anything with a machine in it
- the boys only from behind; nobody else identifiable without a sign-off
- nothing with plates or addresses legible

Drops named `ski-*`, `fish-*`, `dog-*`, `boat-*` go straight into the About
carousel. `scripts/intake_photos.py` can also pull candidates from the Mac
Photos library or a Google Takeout folder; ticked picks land here.
