How this site was built

The build

Hand-written HTML and CSS. No framework, no CMS, no build pipeline beyond two small Python scripts: one stamps the version and deploy date into the footer so they can never be typed wrong, and one inlines the diagrams. Hosted on GitHub Pages. Pages start from a shared skeleton and get written by hand from there.

Type is Barlow for display and body, Barlow Condensed for labels and stats, IBM Plex Mono for code and captions, all self-hosted as woff2 files totaling about 60K. The palette is a warm gunmetal with one accent, a safety yellow borrowed from workwear, because most of what this site shows is diagrams and dashboards and they read best on a dark ground.

The status rail

The strip at the top of every page reports real state: how many n8n workflows exist across my three systems, how many are active, and when the last one ran. An hourly workflow queries the n8n API and writes a small JSON file into this site's repository; the page reads it on load. If the file fails to load you see the values from the last deploy, never an error. It is there because the systems described on this site are running while you read about them.

The diagrams

Workflow diagrams are rendered from actual n8n workflow exports into the site's own colors and type. Architecture diagrams are drawn by hand in the same language. Each carries a line saying how it was made.

Deliberately left out

No analytics scripts, no cookies, no consent banner because there is nothing to consent to. The one script that phones home is a visit beacon that fires only when a URL carries a code I handed out myself, and it reads nothing from your browser. No gradients, no glassmorphism, no scroll animations, no testimonial carousel, no logo strip, no stock illustration. No em-dashes either, down to the commit messages, for reasons that are between me and my drafts.

The rules the copy follows

Every number traces to a maintained achievement inventory or does not appear. Revenue I influenced is called influenced. Things built and not yet launched say so. Companies appear by name only where they already appear on my public resume; everyone else is described generically on purpose.
